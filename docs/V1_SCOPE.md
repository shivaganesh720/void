# VOID V1 Scope Freeze

## Scope statement

VOID V1 is a governed local Resume/JD intelligence slice that proves the control-plane model: intent capture, policy-aware execution, file validation, structured analysis, mission tracking, evidence, and truthful reporting without uncontrolled autonomy.

This repository currently implements the local, bounded slice of that system. It is not a complete multi-user production AI operating system.

## In-scope V1 use case

- Create a user account
- Log in securely
- Create a project
- Upload a resume
- Upload or paste a job description
- Select execution mode
- Launch a mission
- Inspect mission lifecycle and task state
- Review evidence-backed matching and gap analysis
- Receive truthful recommendations
- Receive an execution explanation report
- Download or inspect generated artifact metadata
- View mission history

## Non-goals for V1

The following remain explicitly deferred or future:

- Voice control
- OCR and scanned PDF processing
- Full RAG and knowledge memory system
- Workflow marketplace
- Capability marketplace
- Native mobile or desktop clients
- Unrestricted browser automation
- Uncontrolled side effects
- Uncontrolled agent-to-agent communication
- Distributed workers or queuing infrastructure
- Full model council
- Large autonomous learning

## Current repository position

The runtime is a verified local development slice centered on deterministic Resume/JD analysis, with support for authenticated demo-style access, project membership checks, and mission storage. The system is intentionally bounded and does not yet satisfy the full multi-user enterprise architecture described in the broader spec.

## Scope decision

The project will continue to prioritize:

1. Safety and bounded execution
2. Working Resume/JD flow
3. Authenticity of reports and evidence
4. Maintainability of the repository
5. Clear separation between implemented and planned functionality

# V1 completion gate

The project is considered complete only when all required V1 checks are satisfied and verified by tests. At the present time, the repo is in a partial but runnable state and should not claim complete V1 readiness.
