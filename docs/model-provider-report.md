# Model and Provider Report

VOID currently makes no external model calls. Resume/JD analysis is deterministic and local. There is no provider registry, model registry, secret-backed configuration, health check, rate-limit handling, fallback routing, cost tracking, privacy mode, or manual/automatic provider selection.

No provider API keys are required or exposed. OpenAI, Gemini, Anthropic, Ollama, OpenRouter, and other providers remain future integrations, not implemented features.
