# VOID User Guide

## Start the local services

Start the backend and frontend using [void-runtime-services.md](void-runtime-services.md). Open `http://localhost:3000`.

## Run Resume/JD analysis

On Dashboard, provide both pasted text inputs or both supported files, then select **Start analysis**. The result shows the mission/task status, score, matching and missing skills, defects, action plan, and evidence.

## Inspect missions

Open **Missions** to search by mission name or ID, filter by status, refresh, and open a mission. Mission details show the current task, execution mode, completion time, lifecycle timeline, and analysis result.

## Current boundaries

The current local store resets when the backend restarts. Settings, approvals, artifacts, agents, providers, tools, memory, workflows, evaluation, and login are not available in this version and are shown as unavailable rather than containing sample data.
