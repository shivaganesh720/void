## Priority conclusion

The highest-value coherent next implementation is authenticated durable mission persistence with repository-scoped access checks, followed by a real background task contract. Agents, providers, tools, approvals, artifacts, memory, workflows, and evaluation should remain blocked until those ownership and execution boundaries exist.

No feature is marked complete solely because a model, route, page, or placeholder exists.
