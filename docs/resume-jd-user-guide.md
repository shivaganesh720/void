# Resume/JD Intelligence User Guide

Open the VOID dashboard. Choose a resume and job-description PDF, DOCX, TXT, or Markdown file, or paste both texts. Start analysis and inspect the mission status, score explanation, matching and missing skills, defects, evidence, warnings, and priority action plan.

The score is an AI-assisted estimate based on recognized terms, not an employer's official ATS score. Add only claims, dates, skills, and metrics that are true and supported by your source documents.
