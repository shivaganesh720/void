# Agent and Capability Report

No executable agent registry, agent harness, capability registry, capability health model, prompt versioning, budget enforcement, or output-schema execution exists in the repository. Policy and strategy modules are pure backend helpers only.

Research, Resume Intelligence, Learning, and Validator agents are not implemented as runtime agents. Capability classes and deterministic routing are roadmap work. These items remain blocked until identity, mission persistence, execution boundaries, and gateway contracts exist.
